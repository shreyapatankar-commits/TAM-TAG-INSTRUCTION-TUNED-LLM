# TAM-TAG-INSTRUCTION-TUNED-LLM
Hinglish TAM Dataset
Tense, Aspect, and Modality (TAM) Classification in Hinglish Code-Mixed Text

This repository provides a publicly available dataset for Tense, Aspect, and Modality (TAM) classification in Hinglish code-mixed text.

The dataset was developed as part of the study:

"Evaluating Tense, Aspect, and Modality Understanding of Instruction-Tuned Large Language Models in Hinglish Code-Mixed Text"

The dataset is intended to support research in code-mixed NLP, linguistic analysis, grammatical classification, and evaluation of multilingual/instruction-tuned language models.

Dataset Overview

The corpus consists of Hinglish sentences written primarily in Roman/Latin script, combining Hindi and English in informal code-mixed usage.

Each sentence is annotated independently for three linguistic dimensions:

Tense
Aspect
Modality

The final publicly released dataset contains:

27,515 unique Hinglish sentences

Each sentence has one label for each TAM dimension.
